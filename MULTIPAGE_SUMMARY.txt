🔧 TECHNICAL DETAILS

═══════════════════════════════════════════════════════════════════════════

GUI Architecture:
  QMainWindow (main window)
    └─ QStackedWidget (page manager)
       ├─ HomePage (page 0)
       ├─ EncodePage (page 1)
       └─ DecodePage (page 2)

Navigation:
  Signals/Slots connect buttons to page switches
  Back buttons always return to home
  Clean state management (reset() on page return)

Threading:
  Long operations in separate threads
  Prevents UI freezing
  Updates propagate back to UI

Styling:
  QSS (Qt Style Sheet) for dark theme
  Consistent color scheme across all pages
  Professional typography
