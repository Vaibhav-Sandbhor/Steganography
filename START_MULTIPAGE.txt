 USAGE EXAMPLE
═══════════════════════════════════════════════════════════════════════════

ENCODING:
  1. Launch: python main_multipage.py
  2. Click "📝 Encode Message"
  3. Click "📂 Select Image" → Choose PNG
  4. Type your secret message
  5. Enter password (twice)
  6. Click "🔒 Encode & Save Image"
  7. Choose save location
  8. ✅ Success! Image vanishes from UI

DECODING:
  1. Launch: python main_multipage.py
  2. Click "🔍 Decode Message"
  3. Click "📂 Select Image" → Choose encoded PNG
  4. Enter password (same as encoding)
  5. Click "🔓 Decode Message"
  6. Message appears in text box
  7. Click "📋 Copy Message" to copy to clipboard
