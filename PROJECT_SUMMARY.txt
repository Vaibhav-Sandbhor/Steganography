## 🎓 How It Works (Simple Explanation)

### Encoding Process:
1. You provide: image, message, password
2. Message is encrypted using AES
3. Message length is encoded
4. Encrypted data converted to bits
5. Each bit hidden in LSB of pixel colors
6. Result: Image looks identical to original! 👀

### Decoding Process:
1. You provide: encoded image, password
2. Extract bits from LSBs of pixels
3. Read message length from first 32 bits
4. Extract encrypted message
5. Decrypt using password
6. Result: Original message revealed! 🔓

```bash

```
- Click buttons, enter text
- Intuitive interface
- Best for users

### Programmatic Usage (Advanced)
```python
from steganography import SteganographyCore

# Encode
success, msg = SteganographyCore.encode(
    "original.png",
    "My secret!",
    "password123",
    "encoded.png"
)
print(msg)

# Decode
success, result = SteganographyCore.decode(
    "encoded.png",
    "password123"
)
if success:
    print(result)  # "My secret!"
```

## 🔐 Security Tips

### ✅ Do's:
- Use strong passwords (16+ characters)
- Mix uppercase, lowercase, numbers, symbols
- Use PNG format exclusively
- Use images ≥1024×1024 pixels
- Don't reuse passwords
- Communicate passwords securely

### ❌ Don'ts:
- Don't use JPG (compression loses data)
- Don't use weak passwords
- Don't store passwords in messages
- Don't send encoded images to untrusted sources
- Don't assume it's unhackable (it's not!)
