🚀 GETTING STARTED IN 3 MINUTES
═══════════════════════════════════════════════════════════════════════════

1. INSTALL DEPENDENCIES
   
   cd c:\Users\Svaib\Downloads\project-main\project-main
   pip install -r requirements.txt
   
   This installs:
   • customtkinter (modern GUI framework)
   • pillow (image processing)
   • cryptography (AES encryption)

2. RUN THE APPLICATION

   python main.py
   
   The GUI will open with:
   • Encode Tab: Hide messages in images
   • Decode Tab: Extract messages with password

3. START USING!

   ENCODE:
   - Click "📂 Select Image" → choose PNG
   - Type your secret message
   - Create a password
   - Click "🔒 Encode Message"
   - Save as PNG

   DECODE:
   - Click "📂 Select Image" → choose encoded PNG
   - Enter your password
   - Click "🔓 Decode Message"
   - Your message appears!

EXAMPLE 2: Python Code

    "MyPassword123",
    "encoded.png"
  )

  success, result = SteganographyCore.decode(

Q: How do I start?
A: 1. pip install -r requirements.txt
   2. python main.py
   3. Click buttons and use the GUI

Q: Is the image modified visually?
A: No! The encoded image looks identical to the original.

Q: Can I hide large messages?
A: Yes! Up to 5 MB in high-resolution images.

Q: What if I forget the password?
A: The message is encrypted. Without the password, it's unrecoverable.

Q: Is this secure enough?
A: Yes! It uses military-grade AES-128 encryption.

Q: Can anyone detect the hidden message?
A: Not with naked eye. Advanced tools might detect the presence of data,
   but this is an educational tool, not military-grade.

Q: Do I need internet?
A: No! Completely standalone application.

Q: Which Python version?
A: Python 3.8 or higher is required.

📞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Problem: "pip: command not found"
Solution: Use "python -m pip install -r requirements.txt"

Problem: "No module named customtkinter"
Solution: Run "pip install --upgrade customtkinter"

Problem: "GUI won't open"
Solution: Update libraries: "pip install --upgrade customtkinter pillow"

Problem: "Message too large"
Solution: Use a larger image (≥1024×1024 recommended)

Problem: "Wrong password" error
Solution: Passwords are case-sensitive, check carefully

For more help: See SETUP_GUIDE.md troubleshooting section
